# 식재료 입력 기능

## 입력 모드

### 수동

input을 최대한 줄이고 '간편함'에 가장 초점을 맞춘다.
타 서비스 살펴봤을 때, 상품 이름 입력칸에 강력한 자동완성을 걸어놓고 있었다.
유통기한은 식품부에서 제공하는 해당 식재료의 평균 소비기한을 바탕으로 제안.

### 자동

타 플랫폼 주문 정보 연동을 통한 자동 입력

#### 문제

  - naver → gmail 수신 설정을 추가해 gmail로 받아서 처리.. 가능은 하지만 번거롭다.
