# 냉부 — 쿠팡 주문내역 복사 (크롬 확장)

쿠팡 주문목록 페이지에서 구매 품목을 추출해 클립보드로 복사하는 MV3 크롬 확장. 냉부에 식재료를 등록할 때 붙여넣어 쓰는 용도.

## 설치 (개발용)

1. Chrome → `chrome://extensions`
2. 우측 상단 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드** → 이 폴더(`apps/extension`) 선택
4. 쿠팡 로그인 후 **주문목록 페이지**(`https://mc.coupang.com/ssr/...` 계열)로 이동
5. 확장 아이콘 클릭 → **주문내역 복사**

## 동작

1. **이후 주문 날짜**(선택) 입력 → **불러오기**
2. 현재 탭(쿠팡)에서 `chrome.scripting.executeScript`로 크롤러 실행 → `/ssr/desktop/order/list?pageIndex=0`부터 SSR HTML을 `fetch`(로그인 쿠키 자동 포함)해 파싱, `pageIndex`를 올려가며 신규 품목이 나오는 동안 반복
3. 추출한 품목을 **체크리스트로 표시** — 식재료 추정은 기본 체크, 비식재료 추정은 기본 해제. 사용자가 자유롭게 포함/제외
4. **선택 복사** → 체크된 품목만 클립보드로 (목록 + JSON)

> eat-me API 직접 전송은 인증(확장↔eat-me) 설계가 필요해 보류. 지금은 복사 후 붙여넣기 방식.

### 날짜 필터

- 페이지에 **주문일(연도 포함)** 이 있으면 입력한 날짜 이후만 수집하고, 최신순이라 기한보다 과거인 페이지에 닿으면 중단
- 주문일을 못 찾으면 필터를 적용하지 않고 전체 수집(상태줄에 안내)

### 페이지네이션 안전장치

- **종료 조건**: 어떤 페이지에서 신규 품목이 0건이면(빈 페이지/마지막 반복) 중단
- **상한**: 최대 `MAX_PAGES`(기본 30) 페이지
- **딜레이**: 페이지 간 400ms (쿠팡에 부담·이상탐지 방지)

빌드 스텝 없음(바닐라 JS). 수정 후 `chrome://extensions`에서 새로고침만 하면 반영됨.

> ⚠️ SSR HTML을 fetch해 파싱한다. 쿠팡이 페이지 구조를 client-render로 바꾸거나 anti-bot을 강화하면 fetch 방식이 막힐 수 있다. 그럴 땐 각 페이지를 탭으로 열어 읽는 방식으로 폴백해야 한다.

## 추출 방식 (클래스 비의존)

쿠팡 주문 페이지는 styled-components 해시 클래스(`sc-xxxx`)라 클래스 셀렉터는 배포마다 바뀐다. 그래서 안정적인 신호에만 의존한다 ([popup.js](popup.js) `extractCoupangOrders`):

- **품목명**: `<img alt="상품명, 용량, 수량">` (실제 상품 alt는 콤마 포함, 로고는 콤마 없어 자동 제외)
- **가격**: 리프 요소 텍스트 `"5,310 원"`
- **배송일**: `"6/16(화)"`

문서 순서가 `[상품 → 가격 → 배송일]`로 일정해 단일 패스로 페어링한다.

## 식재료 필터

식재료만 복사하도록 `NON_FOOD` 키워드(필름/행주/키친타월/걸이/박스…)로 비식재료를 제외한다. **휴리스틱이라 완벽하지 않다.**

- 제외된 품목은 팝업 미리보기에 `── 비식재료로 제외됨 ──`으로 표시 → 오분류 확인 가능.
- 오분류가 있으면 `NON_FOOD` 목록을 편집하면 된다.
- 정확도가 필요하면 LLM 분류(냉부 API 경유)로 업그레이드 권장.

## 향후 (upgrade path)

- 클립보드 복사 → 냉부 API로 직접 전송(로그인 토큰 필요, CORS/인증 설계)
- 추출 결과를 `createIngredient` 입력값(name/quantity/unit/category/storage/expireAt)으로 정규화
- 컬리 등 다른 플랫폼 추출기 추가
